## 阶段 1 项目骨架：上传 → 存盘 → 文件列表（来源：设计定稿实施阶段 1，全栈）

> 创建于 2026-10-06 22:11

**需求**：浏览器拖文件，服务端收得到、列表列得出（阶段验收标准，见 `docs/project/fileforge/archive/2026-10-06-阶段1-骨架-plan.md`）。

**设计定稿**（`docs/project/fileforge/designs-specs.md`）：

- store 快照式读取：`GetTask` 返回 `TaskView` 值拷贝，per-task 锁 + atomic 完成计数，`-race` 下无竞态；
- handler 层只依赖 service；上传文件流式落盘 `uploads/<taskID>/`，同名文件自动加 `_1`/`_2` 序号防覆盖，文件名剥离路径成分防目录穿越；
- gin `FileFromFS` 对嵌入 FS 会 301 死循环——`GET /` 改为读出嵌入内容后 `c.Data` 返回（被否方案：StaticFS 托首页）。

**实施**：

- `go mod init fileforge` + gin 1.12 + x/image；TDD 全程：先测后码（store 6 测试 → handler 6 测试）；
- `internal/store`（mutex map + TaskView 快照）→ `internal/service`（建任务/落盘）→ `internal/handler`（POST /api/tasks、GET /api/tasks/:id、GET /api/history）→ `main.go`（go:embed + 装配）→ `web/`（拖拽区 + 并发滑块 1~32 + 文件列表）；
- 内联 SVG favicon（现场演示不联网，不依赖任何 CDN）。

**验证**：`go vet` 通过、`go test -race ./...` 全绿、`go build` 产出 22.6MB exe；浏览器实测：上传 3 文件 → 列表渲染文件名/大小/待处理 → 磁盘文件字节级一致 → 控制台无报错。遗留提醒：浏览器对 `localhost` 缓存过首版 301，实测用 `127.0.0.1:8080`。

**涉及文件**：`go.mod`、`main.go`、`internal/store/store.go`、`internal/store/store_test.go`、`internal/handler/task.go`、`internal/handler/task_test.go`、`internal/service/service.go`、`web/index.html`、`web/app.js`、`docs/project/fileforge/designs-specs.md`

## 修复：拖拽区点击选择不可发现（来源：用户反馈，前端）

> 创建于 2026-10-06 22:36

**需求**：用户反馈「没法点击选择」——需要可发现的点击上传入口。

**排查（系统化调试）**：先证伪了「事件递归」假设（Chrome 对已激活的文件选择器，再入 `click()` 为空操作，无栈溢出）；自动化 Chromium 实测点击拖拽区能弹选择框、上传闭环正常——问题不在功能，在**可发现性**：整块虚线区虽可点，但没有任何视觉按钮样式，用户找不到点击入口（用户确认拖拽正常、控制台无报错）。

**实施**：拖拽区内新增真正的「选择文件」按钮（低饱和主题色 `--primary`、hover 加深、无 emoji），按钮点击冒泡到拖拽区复用原处理器，`app.js` 零改动；文案改为「将图片拖到此处，或点击选择」。

**验证**：重建 exe 后浏览器实测——无障碍树出现 button「选择文件」，对按钮触发文件选择框成功，上传 1 文件后列表正常渲染，控制台无报错。

**涉及文件**：`web/index.html`

## 修复续：按钮可见但点击无响应（来源：用户反馈第 2 轮，前端）

> 创建于 2026-10-06 22:42

**排查**：自动化 Chromium 中点击按钮可弹选择框、上传闭环正常，问题仅存在于用户真实浏览器——符合经典跨浏览器坑：`hidden`（display:none）的 file input 在部分浏览器/版本中，程序化 `click()` 不弹选择框。

**实施**：input 从 `hidden` 改为 `.sr-only` 视觉裁剪（已渲染、1px 裁剪，无障碍隐藏）；`app.js` 打开选择器改为标准 `showPicker()` 优先（需用户手势，点击处理器内具备）、`click()` 兜底。

**验证**：重建后自动化实测——input `display:block` 且裁剪生效、`showPicker` 可用、按钮 → 选择框 → 上传（photo_2.jpg 入列表）全链路通过；**待用户浏览器 Ctrl+F5 后复验**。

**涉及文件**：`web/index.html`、`web/app.js`
