# FileForge（文件工坊）

介绍：完全本地运行的批量图片处理工具——单文件 exe、零外部依赖、拖进来就压，解决批量压缩主痛点（隐私 / 广告限制 / 技术门槛），搭车解决重复文件（MD5 去重）与文件名混乱（统一重命名）。本文档由开发者维护（本稿由 AI 依据同目录 `2026-10-06-fileforge-design.md` 设计全记录提炼起草，**待开发者审核定稿**）。

v0.2（草案，待开发者审核；v0.2 新增「压缩程度可选」，其余与 v0.1 一致）：

**批量压缩：**

- 浏览器拖入一批图片（jpg/png，可 200+ 张），批量处理；
- 等比压缩：最长边 > 1920 则等比缩放（`golang.org/x/image/draw` CatmullRom），JPEG 重编码；
- 压缩程度可选：页面提供压缩质量滑块（50~95，步进 5，默认 80），随任务提交；数值越低体积越小、画质越低，最长边 ≤1920 的缩放规则保持固定；
- PNG 统一转 JPEG 输出（取舍：截图文字边缘轻微毛边，换规格统一与体积最优）。

**MD5 去重：**

- 内容相同（MD5 一致）的文件只保留首个，其余标记「重复」，不进结果 zip。

**统一重命名：**

- 处理结果按 `photo_001.jpg` 序列命名。

**实时进度：**

- 处理进度经 SSE 实时推送，进度条无刷新自走；轮询接口作为降级备份。

**并发可调与历史对比：**

- 并发数 1~32 滑块可调；每次任务耗时记录成历史对比表（并发收益演示的核心载体）。

**结果下载：**

- 完成后一键打包 zip 流式下载处理结果。

**交付形态：**

- 全部功能打包单个 exe（前端经 go:embed 嵌入），双击即用，运行时零外部依赖。

**边界：**

- 不做视频处理、水印、格式批量转换；
- 不做多用户 / 登录 / 权限；
- 任务不持久化，存内存，重启即清（有意设计）；
- 单文件失败不中断整批：失败文件标记「失败 + 原因」，仅做 MD5 与原样归档，不进 zip；
- EXIF 方向信息未处理，手机竖拍照片可能方向错误（已知限制）；
- 无前端框架与构建工具，原生 HTML + JS 单页。
